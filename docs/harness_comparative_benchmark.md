**Verdict: NEUTRAL — flag stays OFF.** The taskSuccessRate delta (+2.8%) is well inside its
confidence interval (±10.9%) — seed noise, not signal (flagOn 0.583/0.500/0.583, supervisorOn
0.583/0.667/0.500). No gating-metric regression.

What the run establishes:
- **Stall induction works, INV-22 holds** — the supervisor is consulted on the stall tasks
  (0.417 mean) and never on the healthy ones (0.000 on both arms).
- **No recovery benefit in the single-turn PA path.** Across all 3 seeds, every consulted stall
  task got a `GATHER_EVIDENCE` or `REDIRECT_STRATEGY` directive, and **0 of those recovered**.
  Neither directive re-queues a single failed task — only `REFRAME_PLAN` triggers the GLOBAL
  rebuild that is the sole recovery path when the turn's task graph is one node, and the decider
  never returns `REFRAME_PLAN` for an "injected timeout" digest (correctly — a timeout is not a
  wrong decomposition). The successes on both arms are the runs that recovered *before* reaching
  the stall edge.
- **Real added cost** — ~44% mean cost, ~2× tokens on this mixed slice, concentrated on the
  stalled tasks where the decider fires (~1 added LLM call per stalled task — within the ADR-005
  ceiling, but buying nothing here).

The higher-fidelity measurement is the multi-task / decomposed path (adapter `_run_planner`, or a
decomposed PA turn) where `GATHER_EVIDENCE`'s merged findings and `REDIRECT_STRATEGY`'s strategy
switch have downstream tasks to act on — see the S7 note in
`plans/harness_trajectory_supervisor_plan.html`.
